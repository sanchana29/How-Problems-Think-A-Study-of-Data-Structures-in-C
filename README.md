# "One Problem, Four Data Structures"
A simple C project that demonstrates how arrays, linked lists, stacks, and queues handle the same problem differently.

Problem:
Given {4, 2, 7, 1, 9} and X = 7, find the element immediately after X.

Goal:
Build conceptual clarity by observing the natural behavior and limitations of each data structure.

Tech:
C | GCC | VS Code
